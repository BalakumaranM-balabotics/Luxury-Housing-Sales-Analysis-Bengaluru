# Luxury-Housing-Sales-Analysis-Bengaluru
An end-to-end real estate analytics project focused on understanding luxury housing sales across Bengaluru.
The project uses Python for exploratory data analysis, data cleaning, and feature engineering; MySQL for structured data storage and validation; and Power BI for interactive dashboarding and business insight generation.
The dataset contains 100,000 property transaction records and 22 final analytical columns.
The analysis covers pricing, price per square foot, booking behavior, quarterly trends, builder performance, configuration demand, sales-channel efficiency, possession status, micro-market concentration, and top-performing builders.
Key engineered features include Price_per_Sqft, Quarter_Number, Booking_Flag, and Booking_Conversion_Helper. 
The final dataset is stored in MySQL and used for Power BI visualizations and DAX-based analysis.
